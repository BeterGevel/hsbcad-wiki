    Define custom wall framing styles¶

    Video info

    Source: Watch on YouTube Duration: 9:38 Level: Beginner

    Overview¶

    You will learn how to use the Framing Styles Editor to create custom wall templates from scratch. Setting up proper framing styles allows you to define exact material layers, stud spacings, and sheet distributions so your timber-frame walls generate accurately in the model.

    What you'll build¶

    An exterior wall framing style featuring a structural stud core and continuously staggered OSB sheeting on both faces, where the studs automatically align to back up the sheet splits. You will also duplicate this style to quickly create a thinner interior wall template.

    Prerequisites¶

    • Knowledge: None.
    • Project state: A Revit project is open with the HSBcad add-in active and default families loaded.

    Key concepts¶

    • Framing styles editor — The interface in HSBcad where wall framing styles and their connection details are defined. Open it from the HSBcad ribbon.
    • Framing style — A reusable template that defines the structure of a wall — the layout of its studs, plates, sheets, and other elements. Walls in the model are built from one or more framing styles.
    • Beam code — A short code (for example CD, CDS) assigned to elements in a detail to identify their type or function. Beam codes are used downstream by the construction generator and by reporting.
    • Instance parameter — A property of an element — like width, height, or visibility — that can be adjusted per instance, usually by dragging an edge or editing a value in the parameter panel.
    • Alias — A named placeholder defined in a framing style that maps to a specific Revit material or beam size. Aliases let you describe a framing style abstractly and swap the underlying material in one place.
    • Zone — A distinct spatial layer within a wall framing style — for example the structural stud core, exterior sheathing, or interior sheathing.
    • Zone filler — The logic that determines how a zone is populated when the wall is generated — most commonly Beam Distribution (studs) or Sheet Distribution (sheathing).
    • Rely on — A zone setting that forces the filler of one zone to align with the splits or elements of another zone.

    Step-by-step walkthrough¶

    Open the Framing styles editor (0:00)¶

    Goal: Access the interface where you build and manage wall templates.

    Steps:

    1. Click Framing Styles Editor in the HSBcad ribbon → the Framing Styles Editor dialog opens.

    Verify: The editor window appears, showing tabs for Aliases and Framing Style on the left.

    Define material aliases (0:42)¶

    Goal: Create shorthand names for materials so you can easily assign them to different zones later.

    Steps:

    1. Select Aliases in the left sidebar → the alias configuration panel appears.
    2. Click Add Alias → a new alias row is added.
    3. Type Studs into the text field → the alias is renamed.
    4. Click Add Alias again and type Plywood → a second alias is created.
    5. Click Add Alias again and type OSB → a third alias is created.

    Verify: You see three aliases named Studs, Plywood, and OSB in the list.

    Create a group and framing style (1:13)¶

    Goal: Organize your templates and create the foundational container for an exterior wall.

    Steps:

    1. Select Framing Style in the left sidebar → the inventory and group tree appears.
    2. Click Add Group → a new group appears in the tree.
    3. Select Wall - Exterior Walls from the group type dropdown → the group is categorized for exterior walls.
    4. Click Add framing style inside the new group → a new style template appears.
    5. Type E1 - OSB_Stud184_OSB in the Name field → the style is renamed.
    6. Type OSB_38x184_OSB in the Description field → the description is logged.
    7. Select OSB for the OSB alias, Plywood for the Plywood alias, and 38x184 for the Studs alias in the Inventory mapping panel → the physical materials are mapped to your aliases.

    Verify: The E1 framing style is listed under the Wall - Exterior Walls group with its materials mapped in the inventory.

    Configure the structural stud zone (2:10)¶

    Goal: Define the main load-bearing core layer, including stud spacing and beam codes.

    Steps:

    1. Click the Zones tab → the visual configuration for the wall zones appears with Zone 0 (the core layer) already created.
    2. Select Beam Distribution Filler from the Zone filler dropdown → the beam distribution properties load on the right.
    3. Select Studs from the Material dropdown → the 38x184 stud material is applied to the zone.
    4. Type 610 in the Spacing/Beam field → the stud spacing updates.
    5. Type ST in the BeamCode field → the studs receive the "ST" identifier.
    6. Select Left from the Start distribution dropdown → the studs align their spacing from the left side of the wall.
    7. Click the Inventory tab to return to the material list → the inventory list appears.
    8. Select 38x184 from the Default Beam dropdown → the top and bottom plates update to perfectly match your stud depth.

    Verify: In the visual preview at the bottom, the bottom plate aligns cleanly with the vertical studs without any offsets.

    Add exterior sheet distribution (4:47)¶

    Goal: Apply an outer layer of OSB sheathing that automatically minimizes waste.

    Steps:

    1. Click the Zones tab → the zone editor appears.
    2. Click the + (add zone) button above Zone 0 → Zone 1 is created on the exterior side.
    3. Select Sheet Distribution from the Zone filler dropdown → the sheeting properties appear.
    4. Select OSB from the Material dropdown → the OSB sheeting is applied.
    5. Type 12 in the Thickness field → the sheet depth updates.
    6. Check the Continuously staggered box in the Distribution panel → the sheet layout adjusts to stagger seams continuously.

    Verify: The visual preview shows a solid panel covering the studs, and the 3D view confirms the 12mm thickness is applied to the exterior face.

    Align studs to sheet splits (6:51)¶

    Goal: Ensure there is always a stud positioned directly behind a vertical seam in the OSB.

    Steps:

    1. Select Zone 0 in the zone list → the core layer properties appear.
    2. Type 1 in the Rely On field → the stud distribution recalculates to factor in Zone 1.

    Verify: In the preview, an extra stud automatically generates exactly behind every vertical split in the exterior sheeting.

    Add interior sheet distribution (7:27)¶

    Goal: Mirror the exterior sheathing setup to close off the interior side of the wall.

    Steps:

    1. Click the + (add zone) button below Zone 0 → Zone -1 is created on the interior side.
    2. Select Sheet Distribution from the Zone filler dropdown → the sheeting properties appear.
    3. Select OSB from the Material dropdown → the OSB sheeting is applied to the inside face.
    4. Check the Continuously staggered box in the Distribution panel → the interior sheets stagger.
    5. Type OSB 12 in the Description fields for both Zone 1 and Zone -1 → the layers are clearly labeled.

    Verify: The 3D preview shows the structural core sandwiched between two layers of 12mm OSB.

    Duplicate and modify for interior walls (8:07)¶

    Goal: Quickly create a thinner interior wall template by copying and adjusting your finished exterior style.

    Steps:

    1. Select the E1 - OSB_Stud184_OSB style in the sidebar → the style is highlighted.
    2. Click the copy icon and drag the duplicated style into the Wall - Interior Walls group → the style is duplicated into the new category.
    3. Type I1 - OSB_Stud89_OSB in the Name field → the interior style is renamed.
    4. Click the Inventory tab → the material mapping appears.
    5. Select 38x89 from the Default Beam dropdown → the horizontal plates resize to the narrower depth.
    6. Select 38x89 from the Studs alias dropdown in the inventory list → the vertical studs resize to match the plates.
    7. Click the Zones tab → the zone properties appear.
    8. Type OSB_38x89_OSB in the Description field → the description reflects the new dimensions.

    Verify: Zooming into the top preview shows that the top plate perfectly matches the narrower 89mm studs.

    Common pitfalls¶

    • Unmatched plate and stud sizes — If your studs hang over the edge of your top or bottom plates, ensure you have set the Default Beam in the Inventory tab to exactly match the material mapped to your Studs alias.
    • Floating sheet splits — If you change the width of your sheeting material and your studs do not align with the seams, you must set the core zone to Rely on the sheet zone (e.g., Zone 0 relies on Zone 1).
