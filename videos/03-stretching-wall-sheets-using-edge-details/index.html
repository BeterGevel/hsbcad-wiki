    Stretching wall sheets using edge details¶

    Video info

    Source: Watch on YouTube Duration: 3:28 Level: Intermediate

    Overview¶

    Learn how to use edge details to fix sheathing sheets (like OSB) that do not extend fully to the top and bottom of your timber frame walls. You will also learn how to create detail configurations, allowing you to easily swap between different parametric variations—such as a single or double base plate—without building separate details.

    What you'll build¶

    You will create top and bottom edge details using the Cut tool to stretch the sheathing sheet across the full height of the wall. You will also add a parametric configuration to the bottom detail so you can toggle the second base plate on and off.

    Prerequisites¶

    • Knowledge: Basic familiarity with the Framing Styles Editor.
    • Project state: A Revit model with an generated HSBcad wall where the exterior sheathing sheets fall short of the top and bottom structural plates.

    Key concepts¶

    • Framing styles editor — The interface in HSBcad where wall framing styles and their connection details are defined. Open it from the HSBcad ribbon.
    • Edge detail — A detail that handles what happens at the top and bottom of a sheet within a framing style.
    • Beam code — A short code (for example CD, CDS) assigned to elements in a detail to identify their type or function.
    • Generate — The HSBcad command that applies the current framing styles and details to the selected model elements and produces the actual timber-frame construction.
    • Construction — The set of framed wall elements (studs, plates, sheets, connectors) produced by the Generate command.
    • Yes/No parameter — A user-defined boolean parameter used to toggle elements or behaviours in a detail on and off.
    • Cut — An auxiliary geometry tool inside a detail that stretches or trims an element (a beam or sheet) by targeting its beam code.
    • Configuration — A named, saved snapshot of all parameter values inside a detail. Configurations let you switch between design variants without rebuilding the detail.

    Step-by-step walkthrough¶

    Creating the top edge detail (0:20)¶

    Goal: Open the framing styles editor and define a new detail that stretches the wall sheet up to the top plate.

    Steps:

    1. Click Framing Styles Editor in the HSBcad ribbon → the editor dialog opens.
    2. Click the Edge Details tab for your target framing style → the edge details list appears.
    3. Click Add Detail under the top wall diagram → the detail editor opens with a default top edge detail.
    4. Select the horizontal top beam in the detail viewer → the Beam parameters panel appears.
    5. Type TP in the Beam code field → the beam code is updated to identify the top plate.
    6. Click Cut in the Tools menu on the Auxiliary Geometry tab → the cut tool activates.
    7. Click in the detail viewer directly above the wall → an upward-pointing arrow appears to indicate the stretch direction.
    8. Select the newly placed arrow → the Cut parameters panel appears.
    9. Type CDS in the Beam codes field → the cut tool now targets and stretches the sheathing sheet.
    10. Type W_Top in the Name field inside the Detail Template panel → the detail is renamed.
    11. Click OK → the detail is saved and you return to the main edge details list.

    Verify: The W_Top detail is now listed in the top position of the edge details menu.

    Creating the bottom edge detail (1:22)¶

    Goal: Create a complementary detail for the base of the wall to stretch the sheet downwards.

    Steps:

    1. Click Add Detail under the bottom wall diagram in the Edge Details tab → the detail editor opens for the bottom edge.
    2. Click Cut in the Tools menu on the Auxiliary Geometry tab → the cut tool activates.
    3. Click in the detail viewer below the wall → a downward-pointing arrow appears.
    4. Select the downward arrow → the Cut parameters panel appears.
    5. Type CDS in the Beam codes field → the tool is configured to stretch the sheathing sheet downwards.

    Verify: A downward-facing cut arrow is placed below the base plate, carrying the CDS beam code.

    Adding configurations to the bottom detail (1:51)¶

    Goal: Create a parameter to toggle a second base plate on and off, then save both variations as reusable configurations.

    Steps:

    1. Click Add yes/no parameter in the Parameters panel → a new parameter appears.
    2. Type No Second Beam into the parameter name field → the parameter is renamed.
    3. Select the bottom-most horizontal beam in the detail viewer → the Beam parameters panel appears.
    4. Check the box next to Set width to 0 and select No Second Beam from the adjacent dropdown menu → the parameter now controls whether the beam has a physical width.
    5. Check the box for No Second Beam in the Parameters panel → the second beam collapses and disappears from the detail viewer.
    6. Click Add configuration (the + icon) in the Configurations panel and type Single Beam → the one-beam state is saved as a new configuration.
    7. Click Add configuration again and type Two Beams → a second configuration is added.
    8. Uncheck the No Second Beam box while the Two Beams configuration is active → the second base plate reappears in the viewer.
    9. Click OK → the detail editor closes.
    10. Click OK in the main Framing Styles Editor dialog → your changes are saved to the project.

    Verify: Back in the main editor dialog before clicking OK, the bottom edge detail displays both the Single Beam and Two Beams configurations in a dropdown underneath it.

    Generating the new construction (2:37)¶

    Goal: Apply the updated framing style to the model so the sheets span the full height of the wall.

    Steps:

    1. Select the target wall in the Revit model → the wall is highlighted.
    2. Click Generate in the HSBcad ribbon → the framing is rebuilt and the sheathing sheet extends fully to the top and bottom plates.

    Verify: The visual gap between the sheathing sheet edges and the top/bottom plates in the 3D model is completely gone.

    Warning

    If the sheathing does not update successfully on the first try, select the wall, click Remove Construction in the HSBcad ribbon to clear the old framing, and then click Generate again.

    Common pitfalls¶

    • Construction does not reflect detail changes — Sometimes Revit caches the old construction state. Select the wall, click Remove Construction, and click Generate again to force a clean rebuild.
