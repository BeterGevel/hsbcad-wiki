    Glossary¶

    Canonical definitions for HSBcad and Revit terms used across this wiki. Every video page links its terms here so definitions stay consistent.

    When a new term is introduced in a tutorial that isn't listed here yet, it appears as a glossary-add comment in the draft. Promote it to this file before publishing the video page.

    Alias¶

    A named placeholder defined in a framing style that maps to a specific Revit material or beam size. Aliases let you describe a framing style abstractly ("the stud material", "the sheathing material") and swap the underlying material in one place.

    Framing styles editor¶

    The interface in HSBcad where wall framing styles and their connection details are defined. Open it from the HSBcad ribbon.

    Framing style¶

    A reusable template that defines the structure of a wall — the layout of its studs, plates, sheets, and other elements. Walls in the model are built from one or more framing styles.

    Detail¶

    A reusable connection design defined inside a framing style — for example a corner detail, an edge detail, or a junction between two framing styles. Details are parametric and can be reused across the model.

    Preview style¶

    A temporary visual setting inside the Framing styles editor that lets you preview how a detail adapts to different wall thicknesses or framing styles. Changing the preview style affects visualisation only, not the saved detail.

    Offset line¶

    A reference line inside a detail used to align and anchor elements. Offset lines can be parametric so the distance they represent (for example, the gap between two walls) can be controlled by a parameter.

    Anchor / anchoring¶

    The act of locking an element in a detail to a reference (an offset line, another element, or the boundary of a sheet) so its position updates automatically when the reference changes. Anchored elements stay in the correct place when the wall thickness or other parameters change.

    Beam code¶

    A short code (for example CD, CDS) assigned to elements in a detail to identify their type or function. Beam codes are used downstream by the construction generator and by reporting.

    Element inventory¶

    A library of predefined beams and sheets you can insert into a framing style or detail. Each framing style has its own inventory of default beams that you can pull from.

    Free inventory item¶

    An element added manually to a detail (rather than from the framing style's predefined inventory) that exposes instance parameters so its dimensions can be adjusted per detail. Commonly used for OSB sheets and trim pieces.

    Instance parameter¶

    A property of an element — like width, height, or visibility — that can be adjusted per instance, usually by dragging an edge or editing a value in the parameter panel.

    Distance parameter¶

    A user-defined parameter that stores a length value (for example, the size of a gap). Distance parameters can be referenced by offset lines and element dimensions to make a detail fully parametric.

    Yes/No parameter¶

    A user-defined boolean parameter used to toggle elements or behaviours in a detail on and off. A common pattern is to drive an element's width with a yes/no parameter so the element disappears when toggled off.

    Connector beam¶

    A beam in a connection detail that bridges two framing styles — typically used to mechanically tie wall structures together at a corner or junction.

    Generate¶

    The HSBcad command that applies the current framing styles and details to the selected model elements and produces the actual timber-frame construction. Found on the HSBcad ribbon.

    Construction¶

    The set of framed wall elements (studs, plates, sheets, connectors) produced by the Generate command from a framing style or details.

    Configuration¶

    A named, saved snapshot of all parameter values inside a detail. Configurations let you switch between design variants of the same detail (for example, single-plate vs. double-plate) without rebuilding the detail from scratch — you create one detail, then save several configurations that toggle its parameters.

    Cut¶

    An auxiliary geometry tool inside a detail that stretches or trims an element (a beam or sheet) by targeting its beam code. Most commonly used in edge details so the sheathing sheet extends up to the top plate and down to the bottom plate.

    Edge detail¶

    A detail that handles what happens at the top and bottom of a sheet within a framing style — for example, ensuring an OSB sheet extends all the way to the wall boundaries.

    Zone¶

    A distinct spatial layer within a wall framing style — for example the structural stud core, exterior sheathing, or interior sheathing. Zones stack from interior to exterior and are numbered relative to the core (Zone 0): positive numbers face outward, negative numbers face inward.

    Zone filler¶

    The logic that determines how a zone is populated when the wall is generated — most commonly Beam Distribution (which lays out studs at a configurable spacing) or Sheet Distribution (which lays out sheathing panels). Each zone has exactly one filler.

    Rely on¶

    A zone setting that forces the filler of one zone to align with the splits or elements of another zone. Typically used so the structural studs in Zone 0 align with the vertical seams of the sheathing in an adjacent zone.

    Item container¶

    A logical boundary placed on a Revit wall that tells HSBcad which portion of the wall to frame. Item containers are the unit of selection for Generate, lock, and renumber operations — without one on a wall, HSBcad cannot produce a construction for it.

    Model group¶

    A named collection of item containers that can be managed, filtered, or generated together as a single unit — useful for grouping all walls of one storey or one building section.

    Match framing styles¶

    The HSBcad command that links Revit wall types to specific framing styles, including alignment (interior, center, exterior) and offset. The mapping is saved with the project so newly drawn walls of those types pick up the right framing automatically.

    Presenter jargon¶

    These are informal terms presenters use in the videos. They are translated to the approved UI vocabulary in tutorial steps; the originals live here as a translation aid.

    Snatch¶

    Drag the cursor onto a reference line or point until it highlights, then release to anchor the element to that reference. Translated to "drag … onto" in tutorial steps.

    Hit¶

    Click a button or invoke a command. Translated to "click" in tutorial steps.
